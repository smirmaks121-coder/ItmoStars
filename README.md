# NetWatcher Pro: Интеллектуальная SIEM/XDR система защиты сетей

Проект разработан специально для конкурса поступающих **ITMO Stars (2026)**.

## 🛡️ Описание проекта
**NetWatcher Pro** — это автономный программный комплекс класса SIEM/XDR для оперативного аудита безопасности и мониторинга локальных сетей (SOHO). Приложение в реальном времени визуализирует топологию сети, определяет типы ОС, выявляет критические уязвимости служб и обнаруживает несанкционированные подключения (Rogue Devices), переводя технические риски на понятный человеку язык рекомендаций (Human-Readable IT).

## 🚀 Ключевые особенности и инновации
* **Clean Code & Архитектура:** Полное разделение логики (сетевой движок на сокетах изолирован от веб-сервера Flask).
* **Субсекундный параллельный движок:** Использование асинхронных пулов `ThreadPoolExecutor` на чистых сокетах Python (без оберток Nmap).
* **OS Fingerprinting:** Распознавание операционных систем (Windows/Linux/iOS) по пассивному анализу метрик TTL пакетов.
* **SIEM-модуль:** Контроль периметра на основе динамических Белых Списков (White Lists) и детектирование MITM-атак (ARP-Spoofing).
* **Интеллектуальный скоринг:** Математический расчет общего индекса безопасности сети (0-100%).

## 🛠️ Технологический стек
* **Backend:** Python 3, Flask
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
